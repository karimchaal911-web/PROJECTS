# Defense and Demo Instructions

## Recommended live sequence

1. Run `web/run_presentation.ps1`.
2. The 15-scene camera tour starts automatically in fullscreen.
3. Let the camera move without clicks. Press Space only when you need more speaking time in the current chapter.
4. Use P for the next-scene cue panel; F for fullscreen; S to restart in safe mode.
5. Use arrows only for Q&A or to revisit Ridge, novelty, validation, or control-room scenes.
6. Home returns to scene 1; End jumps to scene 15; R restarts autoplay.
