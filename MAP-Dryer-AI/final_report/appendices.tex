\section{Reproduction commands}

The report-specific audit is read-only with respect to canonical data and model artifacts. From the project root:

\begin{lstlisting}[language=bash]
$env:PYTHONPATH="src"
python tools/generate_report_enhancement_evidence.py
python -m pytest -q
python tools/validate_report_fields.py
python realtime_pipeline/src/verify_powerbi_views.py
\end{lstlisting}

The first command regenerates the JavaScript Object Notation (JSON) metrics audit, the soft-sensor evidence, the anomaly holdout evidence and the synchronized dashboard captures. The last command requires the configured local PostgreSQL instance. The report itself is compiled repeatedly with \code{pdflatex} so references and contents are resolved.
