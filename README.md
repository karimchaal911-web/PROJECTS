# MAP Dryer AI

Industrial machine-learning project for monitoring and optimising the MAP drying process.

## Objectives

- Predict final laboratory moisture with a regression soft sensor.
- Classify batches as on- or off-specification.
- Detect abnormal operating behaviour and calculate a process health score.
- Present key predictions and drivers in a dashboard.

## Workflow

Raw data → cleaning → validation → feature engineering → exploratory analysis → train/test split → model training → evaluation → dashboard.

## Project layout

- `data/`: raw, processed, and external data sources.
- `notebooks/`: numbered exploratory and modelling notebooks.
- `src/`: reusable data, feature, model, visualisation, and utility code.
- `models/`: saved model artefacts by use case.
- `docs/`, `figures/`, and `reports/`: industrial analysis and project outputs.
- `dashboard/`: dashboard application.
